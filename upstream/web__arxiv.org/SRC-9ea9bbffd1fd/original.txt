Fig. 2. Overview of our computational video montage framework. (Left) During training, FilmGPT from movies via next token prediction. Given an
edited video, each frame is individually tokenized using TiTok-L [Yu et al. 2024], and an additional ⟨CUT⟩ token is added at the boundaries of each shot. For
the purposes of this visualization, each frame is tokenized to one single token. In our actual implementation, each frame is tokenized to a sequence of 32
tokens. Tokens belonging to the same shot are shown in the same color. The ⟨CUT⟩ token is shown with red diagonal stripes. FilmGPT is then trained as an
autoregressive model using next token prediction with interleaved cross-attention layers that attend to the audio features produced by Audio Flamingo 3 [Goel
et al. 2025]. (Right) At inference time, we produce edited video sequences using our footage-constrained decoding algorithm. At each step, the sampling
algorithm chooses and trims a new shot from the video collection V, which is then appended to the original context to select the shot that follows. This
process is repeated until the desired number of shots (or duration) is reached. Thumbnails are copyrighted and belong to EditStock.
